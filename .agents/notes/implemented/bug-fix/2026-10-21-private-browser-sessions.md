# Agent Note: 个人浏览器会话与账号数据隔离

Status: implemented

## Problem

管理页未认证的 GET /api/auto-login 返回服务器全部自动登录配置，导致隐私模式也显示前一个用户的手机号、团队和更新时间。原停用接口还允许仅凭手机号删除配置，前端隐藏并不能修复服务端访问边界。

## Decision

所有账号身份以海康返回的稳定 accountNo 绑定。验证本人有效 Token 或账号密码后，创建仅包含随机标识的 HttpOnly、SameSite=Strict、30 天 Cookie；服务端仅保存其哈希索引，身份、临时 Token 与 CSRF 数据通过 AES-256-GCM 加密持久化。每次登录旋转并撤销该浏览器旧会话，退出撤销服务器记录。持久 Cookie 支持重启后恢复，匿名/隐私窗口不返回个人资料。

个人资料与自动更新状态仅依据服务端会话的 accountNo 读取，忽略客户端请求的其他账号或变量名。Token 更新再次验证 accountNo，停用配置必须有本人会话且绑定仍属于本人。校验 Token 不能利用与旧变量相等的失效 Token 绕过身份验证。公共健康检查只返回成功标记；响应不返回全局数量、无法核验账号数量、其他人的 Token 或 SendKey。后台恢复桥接继续使用独立密钥，不能用于浏览器登录。

默认团队保留当前已选配置，个人已保存团队优先，首次迁移的默认团队保存在加密状态中；匿名访问不下发团队资料。登录面板读取本人今日考勤并展示实际打卡时间；后续任务按 accountNo 记录历史，查询按相同身份过滤。暂无历史时显示今日真实打卡记录，不捏造既往历史。

前端首次载入、页面恢复、切换账号和退出先清空旧 DOM；旧账号迟到的请求响应不允许覆盖新账号。登录流程中仍保留已有账号更新确认及 SendKey 留空保留规则。只读面板不触发打卡、账号密码重登或通知。

## Alternatives considered

仅在隐私模式清空 localStorage 能隐藏本机缓存，但泄露来自公开后端接口，故必须服务端认证并隔离。把海康 Token 直接放 Cookie 更简单，但会将业务凭据交给浏览器，故 Cookie 只存随机会话标识。以手机号或昵称隔离易被请求参数冒用和同名误匹配，故使用验证后的 accountNo。跨用户共享最近一次登录状态无法满足隔离要求，不再采用。

## Consequences

首次访问和隐私窗口必须自行登录，不能跨域读取海康网站的 Cookie。网页会话与后台十天续期独立，退出网页不停止已授权的后台任务。HTTP 部署不能提供传输加密，HTTPS 可显式启用 Secure 属性。历史记录从部署时开始，页面不是完整历史考勤报表。服务更新保留持久密钥与会话文件，失去密钥则关闭会话访问。

## Testing

HTTP 测试验证匿名/新浏览器无资料、两个用户的 Cookie 隔离、跨账号更新与停用拒绝、跨会话 CSRF 拒绝、退出后旧 Cookie 无效及持久化恢复。助手脚本测试验证 accountNo 绑定和失效 Token 不可登录；前端测试验证旧请求不能覆盖新用户及页面隐藏时清理。浏览器使用独立测试账号验证真实登录、刷新恢复、打卡表格和退出清空，不触发真实打卡或通知。


## Deployment verification

2026-10-21 先修复线上公开全量账号状态接口，再通过现有安装器部署完整会话隔离版本，保留旧 release、原核心及加密配置备份。线上匿名 session 返回 authenticated=false，旧自动登录状态接口返回 401。使用已有本人 Token 创建测试浏览器会话，真实读取到本人姓名、默认团队及两条今日/最近打卡记录，团队与现有选择一致。服务重启后同 Cookie 正常恢复，另一个无 Cookie 客户端仍匿名，自动登录状态只含本人一条。退出后复用旧 Cookie 已无效。全部账号、原 Token 和通知 Key 的摘要前后相同，未提交打卡或发送通知。

本地浏览器独立测试账号的登录、页面刷新及退出流程均完成可见验证，同时修正旧 ghost 样式使普通按钮不再绝对定位重叠。线上真实验证使用 HTTP 会话请求进行，未把用户业务 Token 放入浏览器测试或日志。既有 Gitee 订阅来源未修改；新功能的核心导出和历史记录需随仓库订阅同步。
