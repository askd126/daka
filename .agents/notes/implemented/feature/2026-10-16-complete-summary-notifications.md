# Agent Note: 总推送保留全部账号结果

Status: implemented

## Problem

用户查看 2026-10-16 晚间总推送时，只能看到一个账号打卡成功和失败数量，无法看到另一个账号的 Cookie 失效原因。旧逻辑将个人过期提醒去重扩展到总推送，导致统计有失败、明细缺失，全部失败时甚至不发送总推送。

## Decision

每次正常任务的系统总推送列出所有账号及其成功、跳过或失败原因，不因个人提醒已发送或过期事件去重而隐藏账号。不再设置或消费 suppressSummary。用户明确要求失效仍按正常周期推送，因此个人过期通知和系统总推送都按每次正常上下班任务发送；同一 Cookie 只尝试一次自动登录，事件状态不再用于去重通知。兼容接口的 notify 字段始终为 true，任务不依赖它抑制通知。

## Alternatives considered

只补充首次过期的总推送详情可以减少重复文字，但后续任务仍缺少未解决账号的失败原因，因此总推送每次完整列出。额外发送独立故障提醒会增加通知条数，故保持既有总推送并修正内容。

## Consequences

每次任务都可能发送个人失效提醒及系统总推送，持续失效不会静默；这是用户明确要求的正常推送周期，不代表再次自动登录。全部账号失败时总推送仍发送。总推送统计和账号明细一致。

## Related decisions

本决定部分替代 [单次恢复](2026-10-15-expired-cookie-recovery.md) 中排除汇总明细的规则，该篇的单次自动登录仍保留，个人通知去重规则也由本决定替代。检索过期通知和汇总通知笔记，未发现其他同类提案。

## Testing

测试覆盖个人已提醒的过期账号、重复过期事件仍进入汇总与正常个人通知，以及所有账号失败时仍调用一次系统通知。验证通知构造、模拟系统接口及自动登录事件保持单次尝试，不提交打卡、不额外推送测试消息。


## Deployment verification
