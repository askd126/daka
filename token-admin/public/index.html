Token 获取指南

从海康物联复制 www_token

打开登录页 ↗
  1. 1

    点击上方“打开登录页”，使用与海康物联小程序相同的手机号和短信验证码登录。

  2. 2

    进入工作台后按 F12，或在页面空白处右键选择“检查”，打开开发者工具。

  3. 3

    打开“应用程序（Application）”选项卡；如果未显示，可在顶部的 » 菜单中找到。

  4. 4

    依次展开“存储 → Cookie”，选择 https://www.hikiot.com。

  5. 5

    找到名称为 www_token 的记录，复制“值（Value）”栏中的 36 位内容，粘贴到上方输入框并提交。

Token 通常有效 30 天；失效后按相同步骤重新获取并提交。

SendKey 获取指南

从 Server酱 复制 SendKey

打开 Server酱 ↗
  1. 1

    用微信扫码登录 Server酱，进入「SendKey」页面。

  2. 2

    复制 SendKey（形如 SCT 或 sctp<数字>t 开头），粘贴到上方「Server酱 SendKey」输入框。

  3. 3

    不填也可以提交，只是本人不会收到打卡推送。

局域网管理页面
服务监听所有本机网卡。Token 和 SendKey 都不写入浏览器存储、URL 或应用日志，请勿映射到公网。
